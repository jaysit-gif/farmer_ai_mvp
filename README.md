# Farmer AI

One screen after onboarding. Name, district, crop, and language stay in localStorage.

```bash
npm run dev
```

Set `SARVAM_API_KEY` for chat (`sarvam-105b`), speech-to-text (`saaras:v4`), and speech (`bulbul:v4-flash`). Without it, chat can use `XAI_API_KEY` or `OPENAI_API_KEY`. Voice needs the Sarvam key.

Weather comes from Open-Meteo. No account.
